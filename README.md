# 🧠 Govt TenderAI Agent

**Govt TenderAI Agent** is an intelligent, Streamlit-based AI tool designed to analyze Indian government tender documents. It helps contractors, consultants, and businesses extract key sections, understand requirements, compare tenders, and classify user queries as RFIs — all using powerful LLM-based agents.

---

## 🚀 Features

- 📄 **Tender Document Upload**  
  Upload Indian government tender PDFs and process them using a user-friendly web interface.

- 🔍 **Section & Category Extraction**  
  Extract structured information like Eligibility Criteria, Scope of Work, Technical Requirements, etc.

- ⚖️ **Tender Comparison Agent**  
  Compare your tender with a standard template to identify mismatches or missing elements.

- ❓ **RFI Classification Agent**  
  Classify user queries as RFI (Request for Information) or not, based on tender content.

- 🧠 **LLM-Powered Analysis**  
  Utilizes locally hosted open-source LLMs for privacy and performance.

- 🇮🇳 **Made for Indian Tenders**  
  Optimized specifically for Indian government tender formats.

---

## 🛠️ Tech Stack

- [Streamlit](https://streamlit.io/) – Web UI
- [PyMuPDF](https://pymupdf.readthedocs.io/) – PDF processing
- [LangChain](https://www.langchain.com/) – Agent and chain orchestration
- [Open-source LLMs (e.g., Mistral)] – Local language models
- [scikit-learn / custom classifier] – RFI query classification

---


## 🧪 Example Use Cases

- **Contractors comparing bid documents with government requirements**  
  Quickly spot mismatches or missing sections in submitted tenders compared to a standard template.

- **Internal teams verifying tender compliance**  
  Ensure submitted bids meet all eligibility, scope, and technical criteria before final submission.

- **Business analysts drafting RFI queries from tenders**  
  Identify unclear areas in tenders and auto-generate relevant questions using the RFI classification agent.

- **Automating document reviews and extraction**  
  Save time by automating the extraction of critical sections like Scope of Work, Financial Terms, and Submission Deadlines from long tender documents.
